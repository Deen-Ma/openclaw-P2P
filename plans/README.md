# Plan Archive

Store saved `Plan` mode outputs and formal proposals for this repo here.

## Filename convention

Use:

```text
YYYY-MM-DD-HHMMSS-short-title.md
```

Example:

```text
2026-03-11-170500-mabot-telegram-debug-plan.md
```

## Suggested file template

```md
# Title

- created_at: 2026-03-11 17:05:00 +08:00
- mode: Plan
- request: Short description of the user request
- status: proposed | superseded | completed | backfilled

## Plan

<full saved plan text>
```

## Notes

- Keep the original wording of the plan when possible.
- If the content is pasted after the fact, mark `status: backfilled`.
- Add a new file for revisions instead of replacing an older plan.
